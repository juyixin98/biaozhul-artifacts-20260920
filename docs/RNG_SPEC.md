# Random Stream Specification — `stratblock-deterministic-rng-v1`

The randomness is a short, fully specifiable construction (not opaque
NumPy generator state), so an independent implementation can reproduce
every bit. Two independent implementations must agree:

- production kernel: `stratblock/rng.py`
- independent oracle: `reference/pbr.py` (standard library only)

## 1. Stream key derivation (RFC 5869 HKDF-SHA256)

```
salt  = b"stratblock/stream-key/v1"
ikm   = master_seed as 8-byte unsigned big-endian
info  = study_id UTF-8 || 0x00 || stratum_key UTF-8 || 0x00 || b"v1"
prk   = HMAC-SHA256(salt, ikm)
okm   = HKDF-Expand(prk, info, length = 32)
```

`stratum_key` is canonical: factors joined as `name=level`, in the frozen
factor order, separated by `|` (e.g. `age=old|site=A`). Distinct strata
and distinct studies derive independent keys.

## 2. Counter stream

- Blocks: `B_c = SHA256(stream_key || c.to_bytes(8, "big"))`, `c >= 0`.
- Each block yields **eight** 32-bit **big-endian** words, consumed low
  offset first.
- **State invariant:** `counter` = index of the currently buffered block,
  `word` = offset of the next word inside it. Persisting `(counter, word)`
  is sufficient to resume bit-exactly after a restart.

## 3. Uniform integer

```
uniform(bound):   # bound >= 1
    limit = 2**32 - (2**32 mod bound)
    repeat:
        x = next 32-bit word          # ALWAYS consumes a word, even bound==1
        if x < limit: return x mod bound
```

Rejection removes the modulo bias (bound 3 does not divide `2^32`).
**`uniform(1)` still consumes one word** — a tested invariant; skipping it
would desynchronise every later draw in studies with a single block size
or a single eligible arm.

## 4. Block opening and arm sequences

When a new block opens:

1. one `uniform(len(block_sizes))` draw selects the block size;
2. **permuted policy:** build the arm multiset (`count_i = size*ratio_i/R`,
   guaranteed integral by study validation) and Fisher–Yates shuffle
   *positions* `0..size-1`; the block's arms are `multiset[shuffled_positions]`;
3. **balanced_prefix policy:** no up-front permutation; at each position
   `n` (1-based) compute `targets = Hamilton(n, ratio)` and draw
   `uniform(len(eligible))` where `eligible = {i : used_i < targets_i}`.

Consumption is fixed and identical across implementations:

- permuted: `[size draw] + Fisher-Yates(|positions|-1, ..., |positions|-k)` draws
- balanced: one eligibility draw per allocation

## 5. Complete blocks and tails

- Complete block: counts equal `size*ratio_i/R` exactly.
- Permuted open tail: a count vector is on-ratio iff every count is in
  `{floor(n*r_i/R), ceil(n*r_i/R)}` (symmetric feasible-apportionment set).
  Example for 1:1, size 4, n=2: only `(1,1)` is feasible; `(2,0)/(0,2)`
  is flagged. For n=3: `(2,1)` and `(1,2)` are both feasible.
- Balanced-prefix tail: must equal the deterministic lowest-index Hamilton
  apportionment, which the constrained construction guarantees.

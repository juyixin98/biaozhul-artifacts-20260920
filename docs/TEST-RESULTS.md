## 2. curl 端到端示例

命令：

```bash
./examples/demo.sh 18090
```

结果：**退出码 0，全部 8 个场景通过，无连接错误。** 脚本自动启动服务、
投递 17 个位置的事件、中途 `kill` 进程并重启。关键响应摘录：

- 场景 2 回滚后，`id=3` 不出现；`/v1/log?from=1&to=7` 中 `tx-2` 为 `"committed": false`。
- 场景 3 主键变更（pos 9，`id=1 -> id=10`，`pkChanged=true`）提交后：
  - `GET /v1/tables/users/row/10` → 200 `{"id":10,"name":"alice-renamed"}`
  - `GET /v1/tables/users/row/1` → 404 `行不存在: users#1`
- 场景 4 重复 pos=10 → `"status":"DUPLICATE"`；pos=9 改内容重发 → 409。
- 场景 5 先发 pos=13（缺 12）→ HTTP 202：
  `"status":"BUFFERED","state":"PAUSED","firstMissingPos":12`；补齐 pos=12 后自动排空恢复 RUNNING。
- 场景 6 在 pos=16（仅 BEGIN+DATA）后杀进程；重启后 `/v1/status`：
  `"lastDurablePos":16,"lastVisiblePos":14,"openTxCount":1,"openTxIds":["tx-5"]`，
  且表中没有 `id=6`；补 pos=17 COMMIT 后表从 4 行变 5 行，`id=6` 可见。

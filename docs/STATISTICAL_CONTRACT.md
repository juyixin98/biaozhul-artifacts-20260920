# 统计契约与方法说明

本文件把后端实现的统计约定、公式与判定依据固定下来，作为内核与测试共同遵守的契约。

## 1. 检验要素（全部显式）

| 要素 | 字段 | 取值 / 含义 |
| --- | --- | --- |
| 端点 | `endpoint` | `normal` 或 `binomial` |
| 方向 | `alternative` | `two_sided` / `greater` / `less` |
| 显著性 | `alpha` | `0 < α < 1`；双侧检验每尾 α/2 |
| 目标效能 | `target_power` | `α < 1-β < 1` |
| 分配比 | `allocation_ratio r` | `r = n1/n0 > 0` |
| 分析次数 | `interim_looks` | 固定样本承诺只允许 1；>1 直接拒绝 |
| 方法偏好 | `method_preference` | `auto` / `asymptotic` / `exact` |

效应尺度：

- 正态：`standardized_d`（Cohen d，σ 隐式为 1）或 `absolute_difference`（需显式 `sigma`）。
  标准化效应 `d = effect/σ`。
- 二项：`p0` 恒为对照/零假设比例，备择 `p1` 由尺度显式推导：
  - `proportions`：`p1 = effect`
  - `risk_difference`：`p1 = p0 + effect`
  - `relative_risk`：`p1 = p0 · effect`
  - `odds_ratio`：`p1 = ω·p0 / (1 − p0 + ω·p0)`

方向必须与效应一致：`greater` 要求 `p1 > p0`（正态要求效应符号与方向一致由取绝对值处理）。

## 2. 分配契约（整数变量的选择）

规划的整数变量是**对照臂 n0**，处理臂派生：

```
n1 = max(1, round(r · n0))          # 两样本
n1 = 0                              # 单样本
```

两臂样本量都是 n0 的非递减函数，因此效能对 n0 单调。整数搜索（扩张 + 二分）在单调序列上
成立，并且结果可独立复验：

> **接受条件**：`power(n0) ≥ 1−β` 且 `power(n0−1) < 1−β`。

为何不按"固定总量 N + 平局择优"？该定义在奇偶总量间不单调。以 Fisher 例
（p0=.05, p1=.15, 单侧 α=.05, r=1）：N=245 时把额外样本放在对照臂 (123,122) 效能为
0.80003 可达标，但 N=246 的均衡分配 (123,123) 效能只有 0.79377——可行的 245 是"小岛"，
二分搜索会越过它。以 n0 为变量后，边界唯一确定为 n0=n1=126（总 252），n0=125 为 0.79779。

## 3. 正态端点

统计量为均值（单样本）或均值差（两样本，等方差合并）。

- **已知 σ（z）**：检验统计量在备择下服从 `N(λ,1)`，非中心参数
  - 单样本：`λ = |d|√n0`
  - 两样本：`λ = |d| √(n0·n1/(n0+n1))`
  效能：双侧 `S(z_{1−α/2} − λ) + Φ(−z_{1−α/2} − λ)`；单侧取对应尾。
- **未知 σ（t）**：备择下为**非中心 t** `nct(df, λ)`，
  `df = n0−1`（单样本）或 `n0+n1−2`（两样本）。临界值用中心 t 分位数，效能用 nct CDF。

连续解析初值（仅用于给整数搜索定起点，绝不四舍五入当答案）：

```
a* = α/2（双侧）或 α（单侧）
zsum = z_{1−a*} + z_{1−β}
单样本：  n0 = zsum² / d²
两样本：  n0 = zsum² / d² · (1 + 1/r)
```

非中心分布的独立验证（启动自检 + 单测）：

1. `nc=0` 时 nct 即中心 t，`F_{t_df}(t_p) = p`（最坏误差 < 1e-9）。
2. df 很大时非中心 t 效能收敛到 z 效能。
3. SciPy `nct.cdf` 在"负 x、正 nc、大 df"远尾会返回 NaN；用恒等式
   `F_t(x;λ) = 1 − F_t(−x;−λ)` 经稳定的 `sf` 计算回退，绝不让 NaN 冒充结果。

教科书数值（α=.05 双侧，80%）：

| 场景 | 连续值 | 最小整数（本服务） | n0−1 效能 |
| --- | --- | --- | --- |
| 单样本 z，d=.5 | 31.40 | **n0=32**（0.80743） | 0.79501 |
| 单样本 t，d=.5 | — | **n0=34**（0.80778） | 0.79537 |
| 两样本 z，d=.2，r=1 | n0=392.4 | **n0=n1=393**（0.80056） | 0.79956 |

## 4. 二项端点

### 4.1 渐近（正态 score）

- 单样本：`SE0 = √(p0(1−p0)/n0)`，`λ = (p1−p0)/SE0`。
- 两样本：合并 `p̄ = (n0·p0 + n1·p1)/(n0+n1)`，
  `SE = √(p̄(1−p̄)(1/n0+1/n1))`，`λ = (p1−p0)/SE`。
- 连续初值：单样本用零/备择双方差经典式；两样本用 Fleiss 风格式（含 r）。

注意：解析 λ 把 SE 当固定值；实际 score 统计量的 SE 含随机分母。真实"操作效能"由
`tests/reference_oracle.py::score_statistic_power_two` 对全部 (x0,x1) 表**精确枚举**得到，
蒙特卡洛模拟收敛到的是该操作效能。以 p0=.2/p1=.3、n0=n1=295 为例：固定 SE 近似 0.80089，
操作效能 0.80445——差距约 0.004，在夹具 `approximation_allowance=0.015` 内显式记录。

### 4.2 精确单样本（二项检验）

在 `X ~ Bin(n, p0)` 上构造**不超过 α 的最大临界域**：

- greater：最小 c 使 `P_{p0}(X ≥ c) ≤ α`；
- less：最大 c 使 `P_{p0}(X ≤ c) ≤ α`；
- two_sided：每尾 ≤ α/2。

离散性导致保守（如 n=5、p0=.5 时最小可达单侧尾仅 1/32=0.03125），实现如实报告 attained size。
备择效能直接对 `Bin(n,p1)` 在临界域上求和。

### 4.3 精确两样本（Fisher 条件精确检验）

固定边际 `S = X0 + X1` 下 `X1 | S ~ Hypergeom(N, n1, S)`。拒绝域由条件超几何尾对 α 构造。
无条件效能对备择分布混合：

```
power = Σ_s P(S=s) · P_{X1|S}(拒绝 | s)
      = Σ_s Σ_{x1} 1{拒绝(s,x1)} · Bin(x0;n0,p0) · Bin(x1;n1,p1),   x0 = s − x1
```

实现用对数概率 + `logsumexp` 求条件权重，并只访问备择分布有效支撑（对数质量 > −70 的 x0/x1）；
低基率下 S 集中在极少数取值，使得在近似最不可靠的场景精确计算仍可承受。

## 5. 方法选择（AUTO）与失败分类

1. 用连续初值的分配计算最小期望单元格数。
2. `≥ SSP_APPROX_MIN_EXPECTED`（默认 5）：用渐近内核；否则切换精确内核并记录 warning。
3. 整数搜索后在**最终分配**复检期望数：若才跌破阈值，AUTO 改用精确**重新搜索一次**；
   用户 `method_preference=asymptotic` 强制时则以 `approximation_invalid`（HTTP 409）失败。
4. 超出精确上限：`exact_cap_exceeded`（409）。效应趋零导致连续估计越安全上限：
   `effect_too_small`（422）。任何未知/数值异常都不会被折叠成成功。

## 6. 证据（独立蒙特卡洛）与可复现

- 模拟与内核**不共享效能计算**：直接用种子 RNG 生成合成数据并执行真实检验步骤
  （正态 z/t、二项 score、精确二项临界域、Fisher 条件尾）。
- 种子由 `sha256(run_id:purpose)` 确定性派生；同 run 同种子可逐位复现。
- 返回估计效能、拒绝数、MCSE 与 95% 二项区间；判定标准：解析值落在模拟 95% 区间内即"一致"。
- 参考答案来自 `tests/reference_oracle.py`（仅依赖 scipy 原语）与 `data/fixtures/*`，
  **不是由被测内核生成**。

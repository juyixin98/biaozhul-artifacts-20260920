# 正则小子集语言规范

本项目自定义并实现了一个正则表达式的**小子集语言**，包含完整的工具链：

```
源码字符串
  → Lexer   （手写词法分析，Token 带源码位置）
  → Parser  （手写递归下降，AST 带源码位置）
  → Builder （Thompson 构造，NFA）
  → 模拟器 （活跃状态集，逐码点推进）
```

核心解析与匹配**没有使用任何现成正则库/编译器**（代码中不 import
`re`）。Python 的 `re` 仅出现在基准脚本 `scripts/benchmark_backtracking.py`
里，用来对比演示指数回溯，不属于引擎本身。

---

## 1. 语法（EBNF）

```ebnf
pattern     := alternation
alternation := concat ('|' concat)*
concat      := quantified*
quantified  := atom quantifier?
quantifier  := '*' | '+' | '?' | '{m}' | '{m,}' | '{m,n}'
atom        := char | '.' | class | anchor | '(' alternation ')'
class       := '[' '^'? classitem+ ']'
classitem   := literal | literal '-' literal | classescape
anchor      := '^' | '$' | '\b' | '\B'
```

- **连接**（concatenation）：相邻即连接，如 `abc`。
- **选择**（alternation）：`a|b|c`，优先级最低。
- **括号**：`(...)` 分组并改变优先级。本语言**没有捕获组**，括号仅用于
  分组，不产生编号。
- **有限重复**：
  - `*` 等价 `{0,}`，`+` 等价 `{1,}`，`?` 等价 `{0,1}`；
  - `{m}` 恰好 m 次；`{m,}` 至少 m 次；`{m,n}` m 到 n 次；
  - 所有重复默认**贪婪**。不支持非贪婪后缀（`*?`）和占有后缀（`*+`），
    遇到会报带位置的错误；
  - 连续裸量词非法（`a**` 报错），但量词作用于**分组**合法（`(a*)*`）。

空模式与空分支是合法的：`""`、`(|a)b`、`a|` 都接受空串匹配。

### 1.1 重复上限

有限重复通过 Thompson 展开为具体副本，因此设上限 **m、n ≤ 1000**，
超过在词法期报错。无界重复（`*`、`+`、`{m,}`）通过 NFA 环实现，不受此限。

## 2. 字符与转义

### 2.1 普通字符

除元字符外的字符匹配自身。元字符为：

```
. ^ $ ( ) | * + ? { } \ [ ]
```

元字符前加 `\` 即按字面量匹配，如 `\.`、`\(`、`\\`、`\/`。不成量词的
裸 `{`、`}` 按普通字符处理（例如 `a{,3}` 匹配字面 `a{,3}`）。

### 2.2 支持的转义

| 转义 | 含义 |
|---|---|
| `\n` `\r` `\t` `\f` `\v` `\0` `\a` `\e` | LF / CR / Tab / FF / 垂直制表 / NUL / BEL / ESC |
| `\xHH` | 恰好 2 位十六进制码点 |
| `\uHHHH` | 恰好 4 位十六进制码点 |
| `\d` `\D` | 数字 / 非数字 |
| `\w` `\W` | 单词字符 / 非单词字符 |
| `\s` `\S` | 空白 / 非空白 |
| `\b` `\B` | 单词边界 / 非边界（仅作锚点，**不允许**放进 `[]`） |
| 其它 `\` + 标点 | 该标点字面量（`\.` `\(` `\\` 等） |

明确**不支持**：反向引用（`\1`、`\k<>`）、八进制（`\0` 之外的
`\12`）、`\cX`、Unicode 属性类 `\p{...}`、花括号十六进制 `\x{HH}`、
命名组、环视、模式标志。遇到会给出带源码位置的错误。

### 2.3 字符类 `[...]`

- 区间：`[a-z0-9_]`；端点可以是单字符或简单字符转义（`[\x41-\x5a]`）。
- 取反：`[^0-9]` 表示“集合之外的**任意码点**”，因此 `[^x]` 也匹配换行。
- 类内 `]` 紧跟开头时按字面量：`[]a]` 匹配 `]` 或 `a`；`[^]a]` 取反。
- 结尾的 `-` 按字面量：`[a-]` 匹配 `a` 或 `-`。
- 类内可使用 `\d \w \s` 及其大写取反形式。
- 区间反向（`[z-a]`）报错；不支持 POSIX 类与嵌套 `[`。

## 3. Unicode 语义（按码点）

- **模式与文本都按 Unicode 码点处理**：输入是 Python `str`，匹配按
  `ord(chr)` 逐个码点推进，绝不按 UTF-16 代理元或字节切分。非 BMP 字符
  （如 `😀`, U+1F600）是**一个**码点、一次匹配（`😀+` 匹配两个表情）。
- `.` 匹配除换行 `\n`（U+000A）以外的**任意码点**；注意 `\r`、
  U+2028、U+0085 等其它行分隔符**不被排除**（策略固定，无 DOTALL 标志）。
- `\d`：Unicode `Number` 类别（`unicodedata.category` 首字母为 `N`）。
- `\w`：Unicode 字母/数字（`str.isalnum()`）外加下划线 `_`。
  因此 `é`、`日` 都是单词字符。
- `\s`：ASCII 空白 `\t \n \v \f \r` 与空格，外加 Unicode `Z*`
  分隔符类别。明确**不含** U+0085（NEL）。
- 大写形式 `\D \W \S` 是上述集合的补集。
- 本语言不提供 ASCII-only 开关，上述策略即唯一行为。

## 4. 锚点语义（零宽断言）

锚点不消耗字符，作为 NFA 状态上的断言存在：

| 锚点 | 成立条件 |
|---|---|
| `^` | 当前位置是文本开头（码点偏移 0）。**没有**多行模式，不按行匹配。 |
| `$` | 当前位置是文本结尾。**没有**多行模式，也**不**允许“结尾换行前”这一特例：`$` 严格要求位置等于文本长度。 |
| `\b` | 单词边界：位置一侧是 `\w` 码点、另一侧不是（含字符串两端）。 |
| `\B` | `\b` 的否定。 |

`\b`/`\B` 依据第 3 节的 Unicode `\w` 定义判断。

---

## 5. 匹配方式与“左most-最长”规则

引擎提供三种方式（JSON `mode` 字段 / CLI `--mode`）：

- **`search`（默认）**：在文本中寻找匹配。规则是
  **起始位置最靠左（leftmost）**；在同一可接受起始位置上取
  **结束位置最长（longest）**。先按起点从左到右枚举，再在该起点取最长。
- **`fullmatch`**：整条文本必须被完整匹配（隐含两端锚定）。
- **`prefix`**：只从位置 0 开始，取最长的前缀匹配。

空匹配是允许的：`""`、`a*` 在无 `a` 处可产生 `end == start` 的匹配。

因为匹配由 Thompson NFA 的**活跃状态集合**模拟（而非回溯），运行时间为

```
O(|text| × |NFA状态数|)
```

嵌套歧义量词（`(a*)*`、`(a+)+b`、`(a|aa)*b` 等“灾难性回溯”样例）
**不会**指数退化。

---

## 6. 源码位置

每个 Token 与 AST 节点都带 `Span(start, end)`，`start`/`end` 是
**码点偏移**的半开区间。编译错误返回类型、行列号、span 以及一段
`^^^^` 指示。JSON 服务的错误响应示例：

```json
{"ok": false, "error": {"type": "LexError",
  "message": "quantifier range out of order: {2,1} requires min <= max",
  "line": 1, "column": 2, "span": [1, 6]}}
```

---

## 7. 不支持特性一览（设计上明确排除）

捕获组/命名组、反向引用、环视（lookahead/lookbehind）、非贪婪与占有量词、
模式标志（忽略大小写、DOTALL、多行等）、`\p{}`、八进制、POSIX 类、
原子组、条件表达式、回溯控制动词。这些特性中一部分（如反向引用、环视）
会把语言提升到非正则，无法用纯 Thompson NFA 线性匹配，因此被排除。

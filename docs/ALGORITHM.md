# 算法与精度说明

## 1. 整数/有理数实现

- `BigInt`：符号位 + 小端 base 2³² 肢体向量。乘法为 O(n²) 肢体乘（单肢乘积用 `uint64_t`
  承接，`(2³²−1)² + 2(2³²−1) < 2⁶⁴`，单步不溢出）；除法为二进制长除法；gcd 为二进制
  Stein 算法；十进制 I/O 分别用“乘 10 累加”和“除 10 取余”。
- `Rat = BigInt/BigInt`：构造即约分（gcd 绝对值），分母恒正。比较走交叉乘
  （两分母均为正，符号只取决于分子），不引入浮点。

## 2. 相交判定（两线段均非零长）

记 `u = A.q − A.p`，`v = B.q − B.p`，`w = B.p − A.p`，定义

```
D  = cross(u, v) = ux·vy − uy·vx
sN = cross(w, v)
tN = cross(w, u)
```

### 2.1 D ≠ 0（两线不平行）

直线参数解 `s = sN/D`，`t = tN/D`，唯一候选点
`X = A.p + (sN/D)·u`。判定 s、t 是否落在闭区间 [0,1]：

- 先把分母归一为正（D<0 时分子分母同时取负），再比较 `0 ≤ num ≤ |D|`（纯整数大小比较）。
- 任一参数在区间外 → `disjoint`。
- s、t 都严格在内部（`0 < num < |D|`）→ `cross`。
- 否则为 `endpoint_touch`，按 num 是否等于 0 / |D| 标注 `p`/`q`，否则 `i`。
- 坐标直接构造有理数 `Rat(A.p坐标) + Rat(sN,D) * Rat(u分量)`，由 Rat 完成约分。

### 2.2 D = 0（平行）

- `cross(w, u) ≠ 0` → 两线平行不共线 → `disjoint`。
- 否则共线。投影参数（公共分母 `u2 = dot(u,u) > 0`，可省略）：
  - A.p → 0，A.q → u2，B.p → `kr = dot(B.p−A.p, u)`，B.q → `ks = dot(B.q−A.p, u)`。
  - B 对应参数区间 `[lo,hi] = minmax(kr,ks)`；与 `[0,u2]` 求交：
    - `hi<0` 或 `lo>u2` → `disjoint`；
    - 交集 `[max(0,lo), min(u2,hi)]` 两端相等 → `endpoint_touch`（共线仅一点接触）；
    - 否则 → `collinear_overlap`，端点用
      `X = (A.p·u2 + k·u)/u2` 还原为有理点，并按 (x,y) 字典序输出 start/end。
  - 端点标记区分 B 区间端点来自 B.p 还是 B.q（考虑 B 端点书写顺序翻转）。

### 2.3 零长退化（至少一条 p = q）

- 点×点：坐标相等 → endpoint_touch，否则 disjoint。
- 点×线段 C∈L：`cross(v, C−L.p)=0` 且 `0 ≤ dot(C−L.p, v) ≤ dot(v,v)` 判定点在闭线段上；
  在则 endpoint_touch，并按点积严格介于 0 与 |v|² 之间标注线侧 `i`，否则 `p`/`q`。

零长线段不可能产生“长度为正的重叠”，两个零长点重合也只有一个点，故统一归入
endpoint_touch / disjoint，不会误报 cross 或 overlap。

## 3. 溢出分析（为什么必须用任意精度整数）

设输入坐标为 64 位整数，坐标差 `dx` 量级约 2⁶⁴（含 −2⁶³ 与 2⁶³−1 之差）。

| 中间量 | 量级 | 64 位是否安全 |
|---|---|---|
| 坐标差 dx、dy | ~2⁶⁴ | 否（有符号减法本身也可能越界） |
| 叉积 dx·dy − dy·dx | ~2¹²⁸，且两项可能相加 | **否**，必溢出 |
| 点积 dx² + dy² | ~2¹²⁸ | **否** |
| 交点坐标 A.p·u2 + k·u | 输入·2¹²⁸ 量级 ~2¹⁹² | **否** |

因此从“坐标差”开始所有运算都在 `BigInt` 上进行；输出分子/分母用十进制文本，
位数不受 64 位限制。全程没有任何一步落入定宽整数或浮点，故无溢出与舍入。

## 4. 正确性与不变量

- 端点交换：A、B 的几何集合与端点命名无关。判定中所有分支对 `sN/tN`、`kr/ks`
  都做了区间化处理，标签从归一化端点反推；`tests` 以 4 种排列逐一核对。
- 互斥完备：非平行 → 唯一候选点，按参数位置四分支；平行 → 共线判定后按区间交集
  空 / 单点 / 正长度三分支；退化 → 点包含判定。任意输入恰好落入一类。
- 有理数规范化：分母恒正、构造约分，保证相等的点输出字符串一致，便于逐字对拍。

## 5. 复杂度

单条查询：输入坐标按十进制位数计为 n 时，几何判定为常数次 BigInt 乘除，
主体 O(n²)（肢体乘法）；共线还原含一次 gcd 约分（Stein，O(n²) 量级以内）。
对几十位十进制坐标的批量请求为微秒级/条。

```

stream key = ed790aa511e7fcca2e8b557a9d32caa9e4622c9ff6af3949947b43b4febbc70b
```

## 7. Bugs found and fixed during development (not hidden)

1. `CounterStream` state was not self-consistent across serialisation
   (`counter` pointed at the next block while `word` indexed the current
   one) — in-process runs masked it; replay-after-restart diverged. Fixed
   to buffer the current block.
2. `uniform(1)` short-circuited without consuming a word, desynchronising
   streams for single-block-size studies; fixed to always consume one word
   and pinned by cross-implementation tests.
3. The `REALLOCATION_REFUSED` audit event was rolled back with the raising
   transaction; fixed to commit the refusal event before raising.
4. Sealing a study flipped study status but not persisted stratum states;
   fixed to seal both consistently.
5. A tail "imbalance" was initially judged against one deterministic
   Hamilton tie-break, falsely flagging equally-valid `(1,2)` vs `(2,1)`;
   replaced with the symmetric feasible-apportionment set for the permuted
   policy (balanced-prefix keeps the strict deterministic target).
6. Fixed a validation f-string `NameError` (`r` out of scope) found by tests.

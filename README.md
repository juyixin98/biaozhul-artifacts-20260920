# 扫描线矩形并面积 / 周长（纯后端）

给定一组轴对齐矩形，离线计算其**并集**的面积与周长。纯计算后端：
输入/输出均为 JSON，只涉及坐标与数值，不含任何地图或前端组件。

- 语言：C++17（无第三方依赖，自带极简 JSON 解析器）
- 算法：x 方向扫描线 + y 坐标压缩 + 覆盖计数线段树，复杂度 O(n log n)
- 构建：g++ / make

## 1. 坐标与语义约定

- **坐标系**：二维笛卡尔整数坐标平面，x 向右、y 向上；坐标轴单位统一
  （例如都是米，则面积单位为平方单位、周长单位为同一长度单位）。坐标值
  为 JSON 整数，范围 `int64`：`[-9223372036854775808, 9223372036854775807]`。
- **矩形表示**：`{x1, y1, x2, y2}`，表示半开区域 `[x1, x2) × [y1, y2)`，
  要求 `x1 ≤ x2`、`y1 ≤ y2`（否则请求报错）。
- **半开口径**：每个矩形包含左、下边界，不包含右、上边界。这一口径使
  并集可以逐单位格无歧义地度量：
  - 两个在一条边上**贴合（相邻）**的矩形不共享任何面积，拼合成一个整体，
    公共边两侧都被覆盖，因此**公共边不计入周长**（不会被两个矩形各算一次）；
  - 仅以角点接触的矩形互不覆盖，各自周长独立保留；
  - 完全重合、多重覆盖的区域面积只计一次。
- **周长定义**：并集（作为有限个半开矩形之并，其闭包的）一维边界总长。
  带洞并集的内洞边界计入周长；被完全包含的内部矩形若不形成空洞，其边
  不产生贡献（一个矩形完全落在另一个内部时，并集仍是实心的）。

## 2. 精度

- 单坐标跨度最大为 `2^64 − 1`（`INT64_MIN → INT64_MAX` 的半开长度），
  面积最大可达约 `2^128`，超过 64 位整数。
- 内部全部使用 GCC/Clang 提供的 `unsigned __int128`（面积、覆盖长度、
  周长累加），坐标仍为 `long long`；**全程无浮点**，结果精确。
- 响应中 `area`、`perimeter` 以 JSON **字符串**给出十进制精确值，避免
  下游按 IEEE-754 double 解析时丢失精度；`input_count` 等小整数为 number。

## 3. 退化情形处理

| 情形 | 处理 |
| --- | --- |
| `x1 = x2` 或 `y1 = y2`（点、水平线、竖直线） | 视为空集：面积、周长贡献均为 0；计入 `input_count`，不计入 `nondegenerate_count` |
| 矩形完全重合 / 部分重叠 | 重叠面积只计一次，重叠边界不重复计数 |
| 边贴合（相邻） | 公共边两侧均被覆盖，周长不重复计数 |
| 仅角点接触 | 面积为两矩形之和；周长为两矩形周长之和（半开语义下点不属于双方） |
| 完全包含 | 内矩形四边都不在并集边界上，无贡献 |
| 同一 x 上多个事件（多个左缘/右缘混合） | 按“**先开后关**（+1 在 −1 之前）”排序后逐一作用于线段树 |
| 空数组 | `area=0, perimeter=0`，正常返回 |
| 非整数 / int64 越界 / 缺字段 / `x1>x2` / 非法 JSON | 返回退出码 1，stderr 输出 `{"error": "..."}` |

“先开后关”是竖边不重复计数的关键：在贴合边 `x=c` 上，关闭事件使覆盖
减少一段、开启事件随即补回，单次覆盖长度变化的绝对值之和恰为事件左、右
两侧 y 覆盖集合的**对称差**长度，即该 x 处真正暴露于并集边界的竖边长度。
对覆盖计数恒非负的一系列区间加，按所有 +1 先于所有 −1 执行时，
`Σ|Δ覆盖长度|` 等于前后覆盖集合对称差长度（先加只会扩展、后减只会收缩，
中间不发生交叉抵消）。

## 4. 请求 / 响应

请求（stdin 或文件参数）：

```json
{
  "rectangles": [
    {"x1": 0, "y1": 0, "x2": 3, "y2": 3},
    {"x1": 2, "y1": 2, "x2": 5, "y2": 5}
  ]
}
```

成功响应（退出码 0，stdout）：

```json
{"area":"17","perimeter":"20","input_count":2,"nondegenerate_count":2}
```

失败响应（退出码 1，stderr；文件打不开为退出码 2）：

```json
{"error":"请求格式错误: rectangles[0] 要求 x1 <= x2 且 y1 <= y2"}
```

## 5. 构建与运行

```bash
make                       # 生成 build/rectunion
./build/rectunion examples/basic_overlap.json     # 文件入参
cat examples/basic_overlap.json | ./build/rectunion   # 或 stdin
make test                  # 单元测试 + 集成测试
make clean
```

编译参数：`-std=c++17 -O2 -Wall -Wextra -Wpedantic`，零编译警告。

## 6. 算法

1. 每个非退化矩形产生两个事件：左缘 `(x1, +1, [y1,y2))`、
   右缘 `(x2, −1, [y1,y2))`；收集所有 y 坐标排序去重做离散化。
2. 事件按 x 排序；同 x 时 `+1` 排在 `−1` 前。
3. 线段树在离散化的 y 基本段上维护区间覆盖计数，并维护：
   被覆盖总长度 `len`、被覆盖连续段数 `runs`。
4. 在每个事件 x：
   - 逐个应用事件，累加根节点覆盖长度的绝对变化 → **垂直边界**；
   - 到下一个事件 x 的板条 `(x, x')` 上覆盖不变：
     面积累加 `len × (x'−x)`；水平边界累加 `2 × runs × (x'−x)`
     （每段上、下各一条水平边）。

参考实现在 `tests/brute_force.hpp`：对小坐标包围盒逐单位格枚举覆盖，
面积=覆盖格数，周长=覆盖格对未覆盖邻格暴露的边数。它与扫描线算法、
CLI 测试中的 Python 参考（`tests/oracle.py`，独立语言与实现）相互独立，
用于交叉验证。

## 8. 验收与实际运行记录

### 8.1 `make test`（单元测试 + 集成测试）

单元测试 `build/test_units`（扫描线 vs 逐格参考），共 20 项检查全部通过：

- 空输入、仅零面积（点/横线/竖线）、单矩形；
- 横向/纵向相邻（公共边不计）、三段并排（同 x 多事件）；
- 对角重叠、完全嵌套、更大外框包含、四块围出的真·环形带洞
  （area=48 perimeter=48，内洞边界计入）；
- 仅角点接触、完全重复、负坐标与十字形、同 x 混合开/关事件；

  340282366920938463426481119284349108225`，周长 `73786976294838206460`）
  验证 `__int128` 运算；

## 9. 限制

- 矩形数量上限受内存与 `int` 下标限制（线段树离散段数 ≤ 2n，实用中
  数百万量级可运行，见性能抽测）；坐标必须是 int64 整数。
- `__int128` 为 GCC/Clang 扩展；MSVC 不支持（本项目按 g++ 验收）。
- 每次调用独立处理一个请求，为离线批处理工具，非常驻服务。

# 多边形裁剪子集（polygon_clip）— 纯后端

简单多边形被**凸多边形**裁剪的离线空间计算后端：JSON 进、JSON 出，
**只输出坐标与数值**，不含任何地图/图形/前端。

- 语言：C++17（仅标准库，零第三方依赖；内置一个约 300 行的极简 JSON 读写器）
- 算法：Weiler–Atherton 式“边相交 + 边界行走”（支持凹的被裁简单多边形）
- 平台：Linux / g++（在 g++ 13.3、x86_64 上实测）

---

## 1. 构建

```bash
make            # 生成 build/polygon_clip
make test       # 构建并运行全部自动化测试（C++ + Python）
make clean
```

## 2. 运行

```bash
# 从文件
./build/polygon_clip examples/01_hand_triangle.json

# 从标准输入
cat examples/01_hand_triangle.json | ./build/polygon_clip

# 输出到文件
./build/polygon_clip examples/01_hand_triangle.json -o /tmp/out.json
```

### 请求 JSON

| 字段 | 类型 | 说明 |
|---|---|---|
| `subject` | `[[x,y],...]` | 被裁剪多边形，必须是**简单多边形**（可凹；自交/自触将被拒绝） |
| `clip` | `[[x,y],...]` | 裁剪多边形，必须是**严格凸多边形**（连续共线点也拒绝） |

顶点按给定顺序构成闭合环（末点不需要重复首点）。顺/逆时针均可。

### 响应 JSON（节选）

| 字段 | 说明 |
|---|---|
| `ok` | 输入合法且处理成功（`EMPTY`/退化也算成功；`SELF_INTERSECTING` 等为 false） |
| `status` | `OK` / `SELF_INTERSECTING` / `INVALID_CLIP` / `INVALID_SUBJECT` / `BAD_JSON` / `BAD_REQUEST` |
| `kind` | `POLYGON` / `SEGMENT` / `POINT` / `EMPTY` |
| `vertices` | 有序顶点；`POLYGON` 为闭合环（不重复末点），`SEGMENT` 为两个端点，`POINT` 为单点，`EMPTY` 为空 |
| `orientation` | 多边形固定为 `CCW`；退化结果为 `NONE` |
| `area` / `signed_area` | 绝对面积 / 有向面积（CCW 为正）；退化结果为 0 |
| `tolerance` | 本次按坐标尺度自动使用的几何容差 |
| `coordinate_system` | 坐标系声明 |

进程退出码：`0` 正常（含 EMPTY/退化），`1` 输入被拒绝或 JSON 错误，`2` 文件/参数错误。

## 3. 坐标系、精度与退化处理（约定）

### 坐标系
- **平面笛卡尔直角坐标**，X 向右、Y 向上（数学约定），叉积 > 0 为逆时针转向。
- 单位由调用方解释（如米），程序**不做任何投影/经纬度换算**；经纬度需先自行投影。
- 所有多边形输出统一规范为 **CCW（逆时针）**。

### 数值精度
- 全程 IEEE-754 `double`。
- 不使用固定全局 ε，而用与数据尺度成比例的容差：
  `tol = 1e-10 * max(1, max|坐标|)`，对 0~10 的坐标约为 `1e-9`，对 1e6 量级约 `1e-4`。
- 交点沿边参数化重投影并夹到 `[0,1]`，同一几何点的不同数值解以 `tol` 网格吸附合并。
- 面积由鞋带公式计算；输出环清理近重合点与共线冗余点。

### 退化与边界接触
- **自交拒绝**：非相邻边真相交、端点自触（捏合多边形）、共线重叠（含相邻边折返）一律
  返回 `SELF_INTERSECTING`。相邻边共线的“路径冗余点”允许（会被清理）。
- **裁剪域**必须严格凸且面积 > 0，否则 `INVALID_CLIP`。
- 内外判定**含边界**：落在裁剪边上的点/沿裁剪边重合的边都保留。
- 交集面积退化时明确分类，坐标仍保证位于裁剪闭区域内：
  - `SEGMENT`：面积为 0 但有两个相距明显的点（边界沿线接触）；
  - `POINT`：收缩为一个点簇（角点/边点接触）；
  - `EMPTY`：无任何交集。

### 关于算法选择
逐半平面的 Sutherland–Hodgman 简单但要求**被裁多边形也是凸的**：当凹多边形与同一条
裁剪边有多段交叠时，它会用沿裁剪边的线段把各段错误“桥接”，产生自交环并使面积虚增
（本仓库 `examples/07_concave_subject.json` 即该情形的复现）。因此本项目采用
Weiler–Atherton 式边界行走：求两边界全部交点 → 细分两条环 → 标记在对方区域内的子段
→ 沿交集边界（被裁在内的弧 + 裁剪域在内的弧，均按 CCW）行走闭合。测试中的随机凹
多边形用例可稳定通过“结果面积 ≤ min(两面积)”与独立栅格面积比对。

## 4. 手算验收案例（矩形）

裁剪域统一取 `[0,10] × [0,10]`（面积 100）。

| 用例 | subject | 期望结果 | 期望面积 |
|---|---|---|---|
| 手算主例 | 三角形 `(-5,5),(5,-5),(15,5)`（面积100） | 矩形 `(0,0),(10,0),(10,5),(0,5)` | **50** |
| 全包含 | 矩形 `[2,8]×[2,8]` | 原矩形 | 36 |
| 无交集 | 矩形 `[-10,-9]×[-10,-9]` | `EMPTY` | 0 |
| 沿边重合 | `(2,-2),(8,-2),(8,2),(2,2)` | `(2,0),(8,0),(8,2),(2,2)` | 12 |
| 退化-线段 | 横条 `y∈[-2,0]` | `SEGMENT`：`(0,0),(10,0)` | 0 |
| 退化-点 | 三角形仅触角点 `(0,0)` | `POINT`：`(0,0)` | 0 |
| 自交 | 蝴蝶结四边形 | `SELF_INTERSECTING`（拒绝） | — |

手算主例推导：三角形三条边为 `y=x`（左）、`y=-x+10`（右）、`y=5`（顶）。
与矩形边界相交于 `(0,0)、(10,0)、(10,5)、(0,5)`，交集即下方矩形，面积
`10 × 5 = 50`。

每个用例都校验：**面积界**（`0 ≤ 结果面积 ≤ min(被裁面积, 裁剪面积)`）与
**结果点均在裁剪闭区域内**（对每条裁剪边叉积 ≥ -tol）。

## 5. 自动化测试

```bash
make test
```

- `src/test_clip.cpp`：直接针对几何内核的确定性单测——手算案例、全包含、无交、
  沿边重合、点/线段退化、自交/自触拒绝、非凸裁剪域拒绝，以及 200 个随机凸域×
  简单星形多边形的面积界与包含性断言。
- `tests/test_integration.py`：通过 stdin 驱动 `build/polygon_clip` 真实进程，
  校验 JSON 契约，并对 40 个随机用例用**独立的栅格采样**（默认 120×120）估计交集
  真实面积与输出比对，同时校验输出不自交、CCW、全部顶点落在裁剪闭区域内。

仅依赖 Python 3 标准库；无需安装任何包。

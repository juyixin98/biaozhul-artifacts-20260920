# 球面距离查询（sphere_dist）

纯后端的离线空间计算服务：输入经纬度坐标，输出**两点球面大圆距离**与**半径范围内的点**。
只输出坐标与数值，**不含地图、不含前端、无网络服务、无第三方依赖**。

- 语言/标准：C++17（仅标准库，内部用 `long double`）
- 地球模型：**正球体**，固定半径 **R = 6,371,000 m**
- 坐标系统：**EPSG:4326**，十进制度；纬度 `[-90, 90]`、经度 `[-180, 180]`
- 请求方式：JSON（文件路径参数或 stdin），JSON 结果打到 stdout
- 构建：`make`（需要 g++/clang++ 等 C++17 编译器）

## 目录结构

```

```

## 构建与测试

```bash
make          # 生成 build/sphere_dist
make test     # 单元测试 + 集成测试
make clean
```

## 使用

```bash
# 文件方式
./build/sphere_dist examples/distance_beijing_shanghai.json

# stdin 方式
echo '{"action":"distance","a":{"lat":0,"lon":0},"b":{"lat":90,"lon":0}}' \
  | ./build/sphere_dist
```

成功退出码 0；失败时 stdout 输出 `{"ok": false, "error": "..."}`，退出码 1。

## 请求 / 响应

### 1) 两点距离 `distance`

请求：
```json
{"action": "distance",
 "a": {"lat": 39.9042, "lon": 116.4074},
 "b": {"lat": 31.2304, "lon": 121.4737}}
```
响应字段：`central_angle_rad`（地心角弧度）、`central_angle_deg`（度）、
`distance_m`（米）、`distance_km`（千米）。

### 2) 范围检索 `range`

请求：
```json
{"action": "range",
 "center": {"lat": 0.0, "lon": 179.0},
 "radius_m": 350000,
 "points": [{"lat": 0.0, "lon": -179.0}, {"lat": 0.0, "lon": 0.0}]}
```
响应字段：`hits[]`（含输入 `index`、规范化后的坐标、`distance_m`）、
`candidate_count`（通过包围盒的候选数）、`hit_count`、`total_points`。
命中保留输入顺序；边界点（距离恰等于半径）计入。

## 数学定义与精度

- 地心角用矢量点积/叉积的 **atan2 形式**（稳定版大圆公式）：
  对单位矢量 n₁,n₂，θ = `atan2(|n₁×n₂|, n₁·n₂)`。
  该形式在重合点（θ≈0）与对跖点（θ≈π）两端都没有抵消病态。
- 距离 = R·θ，单位米。
- 内部全部 `long double`；距离输出 6 位小数（微米），地心角弧度 18 位有效数字。
- 与独立 Python 双精度 haversine 交叉验证，北京—上海等例偏差 < 5×10⁻⁷ m
  （差异来自 Python 的 double，本程序精度不低于它）。

**模型限制（需明确）**：这是半径 6371 km 的球面距离，不是 WGS84 椭球面
（Vincenty/Karney）大地线。与真实椭球面距离相比，典型误差在 0.1%–0.5% 量级，
对跖附近方向退化。需要椭球精度时应改用 GeographicLib。

## 退化与特殊情况处理

| 情况 | 处理 |
|---|---|
| 重合点 | θ = 0，距离精确为 0 |
| 对跖点 | θ = π，距离精确为 πR = 20,015,086.796021 m；多组对跖点族测试 |
| 跨 ±180° 反经线 | 经度差规整到 [-180,180] 取最短弧，如 179°↔-179° = 2° |
| 极点 | 极点处经度无定义，规范化经度为 0；极点间距离与经度无关 |
| 经度 180 | 规范化为 -180（同一经线） |
| 纬度越界 / 非有限数 | 返回错误，退出码 1 |
| 半径 = πR | 包含所有点（对跖点在边界上） |
| 半径 = 0 | 仅命中与中心重合的点 |

极点吸附：纬度与 ±90° 偏差小于 1e-12 度时视为极点。

## 范围检索：包围盒只做候选过滤

两阶段，且**最终一律以精确球面距离裁决**：

1. **候选包围盒**（可误纳、不漏检）：
   - 纬度区间 = [φ0−δ, φ0+δ]（δ = 半径/R），触及极点时**经度全包含**；
   - 经度半宽由球面小圆条件在纬度区间上取最保守值：
     `cos(half) = √(cos²φ0 − sin²δ) / cos φ0`，
     正确处理跨反经线（经度差按 ±π 环绕）。
2. 对候选点逐一算精确大圆距离，`distance <= radius` 才计入 `hits`。

包围盒的“不漏检”由 `tests/unit/test_geo.cpp` 的密集网格扫描保证
（8 个纬度 × 4 个经度 × 6 种半径 × 16,200 网格点）。

# Service call examples (curl)

Start the API locally:

```bash
PYTHONPATH=src python -m uvicorn ipwate.api:app --port 8000
```

All examples use local synthetic data generated by the package. Pipe a
generated payload with a tiny Python one-liner (no files needed):

## 1. Health / config fingerprint

```bash
curl -s http://127.0.0.1:8000/healthz | python -m json.tool
```

## 2. Good-overlap estimate with a traceable request id

```bash
PAYLOAD=$(PYTHONPATH=src python -c "
from ipwate.synthetic import generate_synthetic
import json
d = generate_synthetic(n=2000, scenario='good_overlap', seed=2024)
print(json.dumps({'x': d.x.tolist(), 'a': d.a.tolist(), 'y': d.y.tolist(),
                  'request_id': 'curl-good'}))")

curl -s -X POST http://127.0.0.1:8000/api/v1/ipw/estimate \
  -H 'content-type: application/json' \
  -H 'x-request-id: trace-001' \
  -d "$PAYLOAD" | python -m json.tool
```

The response carries `verdict`, `estimate` (point/SE/95% CI), `weights`
(per-arm Kish ESS), `overlap`, `calibration`, `findings`, per-fold
cross-fitting records, the full `contract`, and a causal disclaimer.

## 3. Positivity violation -> structured 422 (failure category, not a 500)

```bash
PAYLOAD=$(PYTHONPATH=src python -c "
from ipwate.synthetic import generate_synthetic
import json
d = generate_synthetic(n=2000, scenario='no_overlap', seed=9)
print(json.dumps({'x': d.x.tolist(), 'a': d.a.tolist(), 'y': d.y.tolist()}))")

curl -s -i -X POST http://127.0.0.1:8000/api/v1/ipw/estimate \
  -H 'content-type: application/json' \
  -d "$PAYLOAD"
```

Expect HTTP 422 and `error.code = "positivity_violation"` with counts
`treated_p_le_eps` / `untreated_one_minus_p_le_eps`. There is no silent
denominator replacement.

## 4. Poor overlap with the FIXED clipping profile (estimand redefinition recorded)

```bash
PAYLOAD=$(PYTHONPATH=src python -c "
from ipwate.synthetic import generate_synthetic
import json
d = generate_synthetic(n=3000, scenario='poor_overlap', seed=11)
print(json.dumps({'x': d.x.tolist(), 'a': d.a.tolist(), 'y': d.y.tolist(),
                  'clipping_enabled': True}))")

curl -s -X POST http://127.0.0.1:8000/api/v1/ipw/estimate \
  -H 'content-type: application/json' \
  -d "$PAYLOAD" | python -m json.tool
```

`contract.clipping_enabled` is true, `clipping_profile` names the fixed
profile, and `contract.estimand_note` states the estimand is now over a
trimmed population.
